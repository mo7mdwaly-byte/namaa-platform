How to create the token
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate.
  2. Repository access: Only select repositories → pick this repo only.
  3. Permissions: Contents (read/write), Issues (read/write), Pages (read), Metadata (read).
  4. Set a short expiry (30–90 days). Never commit the token to the repo.
